# Referințe vizuale

Acest director e gol la momentul scrierii documentației (`docs/DECISIONS.md`
§2). Adaugă aici capturile de ecran / imaginile de inspirație menționate în
cerința inițială a produsului, înainte de a începe implementarea vizuală
descrisă în `../DESIGN_SYSTEM.md`.

Convenție de denumire sugerată: `<ecran-sau-flux>-<numar>.png`, ex.
`feed-inspiratie-01.png`, `checkin-tableta-02.png`.
